# 戦闘ステージ用の分離素材

3枚は画像生成スキルの組み込みモードで制作した初期素材です。参照元はユーザーと検討した`school-rg-wide-stage-calm.png`と`school-rg-five-junior-high-lineup-draft.png`です。背景、味方、敵を別レイヤーにし、画面とキャラクターを一枚へ焼き込まない構成にしています。

| ファイル | 制作指示の要点 | 状態 |
| --- | --- | --- |
| `stage-hallway-v1.png` | 参照画の広い青系の校内廊下を維持し、人物・敵・文字・UIをすべて除去した環境画 | 初期素材 |
| `girl-notebook-v1.png` | 5人基準画の左端の少女の顔・服・鞄・ノートと中学生らしい比率を維持して透過全身化 | 初期素材 |
| `enemy-paper-v1.png` | 広いステージ案にある紙と机の敵を維持して透過単体化 | 初期素材 |

この3枚は #14 の画面で実際の表示・操作を確認するための素材です。キャラクターの同一性、編集可能原本、待機・発動・被弾・勝敗のアニメーション、別制作回での再現性は #29 の品質ゲートが未完了です。単発生成を最終アートの完了証拠としません。
