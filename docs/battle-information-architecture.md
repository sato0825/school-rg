# 戦闘画面の情報設計（Issue #168）

戦闘の難度や時間制限は変えず、プレイヤーが次の操作を見つける順序を固定する。

1. **今すること** — 残り時間と入力中の語を、操作欄の最初に置く。通常は手札、ポーション入力中はポーションを入力欄の直後に置く。
2. **何に備えるか** — 敵の次の行動を敵の近くに表示する。行動種別は形の違う記号と日本語を併記し、固有の行動名と数値を分ける。
3. **どれを狙うか** — 敵の絵を選択面にし、敵名・HP量・現在値を下部にまとめる。選択中は枠と「対象」を表示する。
4. **補助情報** — 山札などの枚数、ポーション、ログ、遊び方は主経路より小さく扱う。ただし操作不能なほど隠さない。

| 情報 | 主な表現 | 文字の役割 |
| --- | --- | --- |
| キャラクター・敵の識別 | 絵と位置 | 名前で対象を確定する |
| HP | 横バーの長さ、区切り、数値 | 正確な残量と読み上げを補う |
| ブロック | HPと別の菱形バッジ | 数値と効果名を伝える |
| 次の敵行動 | 種別ごとの記号、固定位置の札 | 種別・固有名・数値を明示する |
| 入力可能な時間 | 長さが変わるバー | 残り秒数を明示する |
| 入力対象 | 入力欄と直後の手札またはポーション | タイプすべき英単語を示す |
| カード | 色と形の区別 | 入力語・正確な効果を示す |

色だけで状態を伝えない。数値だけでも量や優先順位を読ませない。低刺激表示は任意で選べ、動きと発光を減らしても、カード発動位置と対象の静止した手掛かりは残す。OSの `prefers-reduced-motion` にも従う。

狭幅の3〜5体編成は Issue #170、支援技術が直接扱える入力先は Issue #169 で追加検証する。現時点の画面だけで、これらの受け入れ条件を満たしたとは扱わない。
