# 購買の在庫（Issue #110）

購買は部活カード3枚、未所持の共用レリック1個、ポーション1個、カード削除1回を提供する。各部活の初期レリックは購買候補から除外する。在庫はシードに従って決まり、購入済みフラグとともに保存される。レリックの購入時には取得hookを発火し、ポーションは枠が満杯なら購入できない。以前のカードだけの購買セーブは、レリック・ポーション在庫を空として読み込む。

カード40G、レリック90G、ポーション25G、削除75G、および候補数は暫定値として `DEFAULT_ECONOMY_SETTINGS` に分離した。ランのゴールド収支、商品価値、約60分の目標は #68 の実プレイで検証する。レリック・ポーションの内容とアートも完成扱いにはしない。
