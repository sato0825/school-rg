# #252 敗北シーケンスの画面・遷移仕様候補

状態: デザイン候補。ランタイムへの組み込みと5部活分の完成素材は別Issue/PRで行う。関連: #243、#29、#177、#150、#228。

## 現状と目的

現在の `src/ui/app.ts` は敗北時に `renderRunResult` へ切り替え、`src/ui/run-view.ts` の `root.innerHTML` が戦闘舞台と人物を取り去る。`src/ui/battle-view.ts` の終端パネルと短い被弾表示だけでは、敵の最後の行動、体力が0になった原因、人物の状態、ラン終了が視覚的につながらない。敗北は同じ舞台上で結末まで見せる。

## 画面構成

- 1440×900と1024×768を基準。ヘッダには階層と体力0/最大値を保持する。カード入力は終端で止め、下部レールは沈静化する。
- 人物は戦闘中と同じ左側の足元アンカーに置き、被弾姿から座り込んだ専用絵に変える。敵も右側に残し、最後の原因の位置を失わない。背景は舞台のまま維持し、人物だけを一段鮮明に描く。
- 中央の広い空間に「敗北」を一度だけ出す。結果の詳細は薄い校内ノートとして舞台に重ねる。ノートは人物と敵の顔・姿を隠さず、到達地点、部活と名前、体力、記録、新しいランへの操作だけを載せる。舞台を覆うフルモーダルや説明文は置かない。
- `docs/design/issue252-defeat-scene.html` は表示候補。`?state=impact|settled|summary` で3時点、`?low=1` で低刺激、`?club=science` で科学部差し替えを見られる。ボタンは見た目の候補で、ゲーム操作には未接続。

## 時系列と遷移条件

| 時点 | イベントと表示 | 入力・次状態 |
| --- | --- | --- |
| `impact` | 敵Intentに一致する最後の行動を解決。体力が0になる位置で局所的なダメージ数値を1回表示し、人物を被弾姿にする。背景全体、ヘッダ、敵名やHPは動かさない。 | タイピング入力を停止。ダメージ解決と敗北判定は同じ決定的な状態更新で行い、二重発動しない。 |
| `settled` | 人物を座り込み専用絵へ切替。敵は動きを止めて彩度と明度を少し下げる。体力0/最大値と「敗北」を保持。 | 遅くとも最後の効果から約0.7秒後。以降の自動敵行動・カード発動は起こさない。 |
| `summary` | 舞台上の空き領域に校内ノートを重ねる。人物と敵は残る。 | `settled` から約1.3秒後、または決定/タップで先へ進む。新しいランへの明確な操作を置く。 |

時刻は演出の暫定値であり、ゲームロジックの敗北成立時刻とは分離する。画面を閉じたりリサイズしても敗北状態は変えない。

## 感覚負荷・操作

- 画面全体の揺れ、全画面フラッシュ、強い残像、連続点滅、派手なBGM停止効果を使わない。最後の一撃の反応は人物・ダメージ数値・小さな音に限り、音声を切っても原因が読めるようにする。
- 低刺激設定と `prefers-reduced-motion` では演出待ちを省き、体力0、座り込み絵、「敗北」、ノートを即時に表示する。ダメージ原因は「最後の敵行動」等の短い記録に残せるようにする。
- 次の操作は主ボタン「新しいランへ」。副ボタンは「記録を見る」。キーボードフォーカスを主ボタンへ移し、Enter/Spaceで発動。結果画面ではタイピング判定器が文字入力を消費しない。スクリーンリーダーは「敗北、体力0、到達地点、次の操作」を一度だけ告知する。
- ノートが入らない場合は人物・敵の上に重ねず、ノート部分だけの寸法と情報量を調整する。横スクロールもスクロール必須の隠れた主操作も作らない。

## アート候補と固定品質の条件

- 文芸部・吉野こはる: `docs/art/candidates/literature-defeat-candidate-v1.png`。既存idle/hit候補の赤い髪留め、クリーム色カーディガン、赤い胸リボン、紺格子スカート、白い花付き靴下、うさぎ付き鞄、ノートを参照。床に座って視線を落とす。統合モック#242の主人公と同一人物として比較する。
- 科学部: `docs/art/candidates/serious-student-defeat-candidate-v1.png`。既存idle/hitの髪留め・制服・鞄・ノートに合わせた座り込み候補。
- 両画像は生成直後の候補で、制作承認・全状態/全角度の同一性保証・ランタイム採用済みではない。採用前に一人ごとの設定画、表情と衣装の一致、透過端、接地、顔の可読性、基準表示寸法、通常/被弾/敗北間の切替を比較し、5部活へ同じ検査を適用する。過度な劇画調や成人体型に寄せない。

## 受け入れ検査

1. PC 1440×900、iPad相当1024×768で、人物の顔・座り込み姿・敵・体力0・次の操作が同時に見える。結果ノートが両者を覆わない。
2. 敗北を確定させる一撃がIntentと一致し、同一フレームでカード発動と時間切れが競合しても敗北演出が一回だけ始まる。HPは二重減算されない。
3. `impact → settled → summary`、スキップ、低刺激、リサイズ、音声オフ、キーボード/タッチの操作で舞台と人物が消えない。敵AI・入力判定は終端状態で進まない。
4. 採用アートの出自、参照元、生成/修正履歴と承認状態が台帳に残る。5部活はそれぞれ同一人物の専用敗北姿を用意する。
