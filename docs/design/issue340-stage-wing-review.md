# #340 講堂舞台袖の代表候補レビュー

Issue [#340](https://github.com/sato0825/school-rg/issues/340) は、[#315のC案](issue315-stage-state-review.md)でP0にした1場所だけを検証する。新しい `auditorium-stage-wing` の v2 を `?experimentalStageWing=on` で Act 3 の11–12Fに仮表示する。通常の12プレート割当、地図、セーブ形式、戦闘/マップ乱数は変えない。13Fボスは従来の講堂舞台へ戻る。場所IDは候補であり、#315の正式な地理規則ではない。

[PC1440とiPad相当1024の比較ボード](issue340-stage-wing-comparison.html)は、同じ文芸部・保存地点・HP・商品/イベントと、[#304の地点小物候補](https://github.com/sato0825/school-rg/pull/334)で現行舞台と舞台袖を並べる。seed97の11F購買・12F休憩、seed42の11Fイベントを到着操作で開き、再読込後に撮った。12画面のSHAは[一覧](previews/issue340-SHA256SUMS)。画像と小物のdecodeを待ち、アニメーションを止めて撮影した2回のPNG SHAは全12画面で一致した。これらは保存状態からの実UIであり、自然な42地点通しプレイではない。

## 通常ルートへの影響と限界

#310のseed42/97の42到着点を同じ地図順で計算すると、元の背景プレート同一連続は両seedで **30/41**、11–12Fだけ舞台袖v2へ変えると **28/41**。入口10F→舞台袖11F、舞台袖12F→ボス舞台13Fの2箇所が区別される。11F→12Fは舞台袖を再使用し、他のActの反復もそのまま。**新規背景候補1枚でラン全体のステージ不足は解消しない。** `light`/ボス接近の低彩度状態や#304小物はプレート数に加算しない。v2も採用済み数には加えない。

## 原本と再制作性

[生成入力・棄却理由・SHA](../art/prompts/issue340-stage-wing-v1.md)と[素材台帳](../art/asset-register.json)に3回の生成系譜を残した。生成PNGは無変更で保存し、v1/v2はOpenRaster原本に入れた。原本は生成ベースのピクセル編集と、独立した照明/遮蔽ペイント層を持つ。ただし生成ベースの壁・床・歩廊は一枚に焼き込まれており、部位別編集、別制作回での完全同一品質、全背景への適用は未証明。#29の正式採用ゲートを満たしたとは扱わない。

## 検証と残作業

自動E2Eは3地点×現行/舞台袖×1440/1024の12画面で、地点到着時だけの背景切替、同じGameShell要素、#304原画decode、セーブ/再読込後の地点・画像一致、購買/休憩操作後の背景不変、横スクロールなしを確認した。単体テストはseed42/97の42地点で30→28の反復と、10F/13Fのフォールバックを検証した。物理iPad、1–3味方と最大5敵の全構成、自然な全ラン、人間の画風/読解評価は未確認。地理・イベント/購買の採用判断は#315、物体原画は#304、継続制作と最終画風は#29に残る。
