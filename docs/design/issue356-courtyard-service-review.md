# #356 Act 1 中庭用務動線の代表候補レビュー

Issue [#356](https://github.com/sato0825/school-rg/issues/356) は、[#315](https://github.com/sato0825/school-rg/issues/315) の有界マトリクスで P1 とした中庭接続場所を1枚だけ検証する。既存の開けた中庭プレートと別に、屋根付きの横方向用務通路を制作した。`?experimentalCourtyardService=on` で Act 1 の11–12Fにだけ候補を表示する。通常の12プレート割当、マップ、セーブ形式、乱数は変えない。10Fと13Fボスは開けた中庭に戻る。これは地理案であり正式採用ではない。

## 事前に指定した破る連続地点

| seed | 元の連続4地点 | 候補の割当 | 断たれる同一プレート遷移 |
| --- | --- | --- | --- |
| 42 | Act 1 10F休憩 → 11F戦闘 → 12F購買 → 13Fボス | 中庭 → 用務通路 → 用務通路 → 中庭 | 10→11、12→13 |
| 97 | Act 1 10Fイベント → 11Fイベント → 12F強敵 → 13Fボス | 中庭 → 用務通路 → 用務通路 → 中庭 | 10→11、12→13 |

両seedの42到着地点で、プレートの連続再使用は元の **30/41** からこの候補だけで **28/41**、[#340](issue340-stage-wing-review.md) の舞台袖候補と併用した場合 **26/41**。11→12Fは用務通路を続けて使う。新しい背景1枚による減少は2遷移であり、これをステージ数や通常ランの完成とは数えない。地点種別と小物の変化も背景プレート数に含めない。

## 本編画面での確認

[PC1440 / iPad相当1024の12画面比較](issue356-courtyard-service-comparison.html)で、seed42の12F購買、seed97の11Fイベントと12F強敵を、同じ保存地点からマップ操作で到着させて撮影した。[撮影PNGのSHA一覧](previews/issue356-SHA256SUMS)を残した。保存/再読込後も地点・背景IDが一致し、同じGameShell要素を使い、画面横スクロールはなかった。これはブラウザ幅の比較であり、物理iPad操作の証拠ではない。

| 観点 | 観察 |
| --- | --- |
| 場所の区別 | 現行中庭の樹木・開放空間から、左の用務扉、右の列柱、奥の中庭への開口へ移る。正面カメラの反復を減らし、校舎接続が読める。 |
| 人物・敵の接地 | 1440/1024の文芸部主人公1人とseed97強敵2体では、足元が画面内の舗装床と重なる。1–3味方/最大5敵の全構成は未確認。 |
| 地点物体 | #304の購買棚を左の空き区画に置き、掲示板を通路の手前に置いた。1024の棚は画像decodeを待った撮影で接地と選択UIからの分離を確認。物体の脚を隠す前景マスクと専用の接地影は未制作。 |
| 画風 | 低彩度の青灰と校舎の紙/ガッシュ調は既存中庭に近い。一方、通路の細かな床・天井ディテールは人物線より密で、全アクトで統一できるかは#29の人間レビュー待ち。 |
| 安定性 | 背景だけをseed・ノードから決定し、セーブには追加情報を置かない。候補の採用・差替えはまだ決めていない。 |

## 原本と採用条件

[生成入力とSHA](../art/prompts/issue356-courtyard-service-v1.md)、[素材台帳](../art/asset-register.json)、OpenRaster候補原本を保存した。生成PNGの壁・床・建具は1ラスター層に焼き込まれ、照明/遮蔽の独立レイヤーは現時点で空。部材別編集や別制作回で安定した同等品質を得る工程は未成立のため、[#29](https://github.com/sato0825/school-rg/issues/29) の最終アート採用ゲートを満たさない。

対象ユニットでは両seedの割当・不変性・連続再使用数を確認し、E2Eでは購買/イベント/強敵×2幅×現行/候補の到着、画像decode、save/reloadを検証した。自然な42地点通しプレイ、物理iPad、複数味方・最大5敵、#29の画風/制作工程の受入は残る。
