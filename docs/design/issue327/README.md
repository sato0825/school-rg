# #327 本編カードの仮入手頻度表示

この表示は #247 の**未承認の初期値**を使う。レアリティの段階、意味、84枚の個票、出現率、ショップ価格は確定していない。`CardSchema`、保存、抽選、価格、ゲーム効果は変更しない。

## 現在の仮設定

`src/ui/card-profile.ts` のカタログを `mountApp` の表示依存として注入し、戦闘手札と報酬が同じ ID を同じ形・枠・短語で表示する。欠落・不正な割当は何も表示しない。「未設定」を低階級の形で代用しない。

初期校正は #247 の調査コメントの分布例 C42 / U28 / R14 に合わせた。共通カードはスターターの8 IDと初期基本行動4 IDを「よく出る」に置き、残りを ID 順で8/4に仮分割した。部活固有は各12枚の ID 順で6/4/2に仮分割した。**これは各カードの役割や強さを評価して割り当てた表ではない。** 入手頻度のUIと画面密度を試すための設定で、正式仕様に転用する前に #247/#68 で個票の役割、提示/選択率、3 Act走行を見て再割当が必要。

見せ方は #316 の実験と同じ輪/菱形/星形、実線/破線/二重線の枠、短い語を採用した。手札では入力語と効果を主情報にし、報酬では選択前に形と短語を読める位置へ置く。色は補助。全バッジの「仮」とアクセシブル名の「仮の入手頻度」は、正式配分ではないことを示す。

## 交換点と残る受入

カタログは `CardProfileCatalog` として UI に注入できる。正式仕様が決まったら ID 配分と名称/形状を差し替える。候補はカード原画に焼き込まず、同じカードIDの強化差分にも同じ表示を使う。

1024/1440の実GameShellと型・E2Eで枠内、入力語/効果との干渉、報酬の3形、AX名を確認する。初見で頻度と強さを混同しないか、実機iPadの判読性、グレースケール/低刺激の人手評価は未検証。#247の正式決定まで完成扱いにしない。
