- Playwright の実戦闘→報酬→経路で舞台・主人公・入力要素の同一性、舞台と主人公の座標（1px未満）、背景を検証。
- 戦闘中マップの開閉、手動停止、IME合成と英数入力復帰、再読込後の経路再構築を検証。
- 1024×768 と 1440×900 の戦闘・経路、1024×768 の報酬を独立ブラウザーで確認。
