# 部活固有カードの仮報酬政策（#94）

5部活の `signatureCardIds` は各部活固有の12枚を明示し、共有24枚を含む `cardPoolIds` の部分集合として検査します。戦闘後のカード報酬は暫定3択で、固有候補がある場合は最低1枠をそこから選びます。残りはその部活の全体プールから重複なく選び、最後に表示順をシャッフルします。固有候補がないコンテンツは全体プールの一様抽選へ戻ります。3 Act最後のボス後はカード報酬を生成しません。

抽選にはランのシリアライズ可能な乱数状態だけを使います。`generateCardRewards` はデータと政策値を受け取り、`settleRunCombat` は生成関数ごと差し替えられます。表示では固有カードに「部活固有」を付けます。これはカードの選択が見えるようにする**仮の配分**であり、正式なレアリティ、出現率、各部活の最終カード量や約60分のバランスは #31/#68 で決めます。
