# ラン履歴

Issue [#150](https://github.com/sato0825/school-rg/issues/150) の履歴は、勝利または敗北でランが終了したときだけ記録します。タイトルと結果画面から開けます。5部活ごとの完走・敗北件数と、終了した各ランの部活、シード、Ascension難度、到達Act/階層、残HP、訪問地点数を表示します。

履歴はブラウザの `localStorage` に `school-rg-history-v1` として保存します。進行中のセーブ `school-rg-run-v1`、Ascension解放 `school-rg-progression-v1`、任意オンのプレイテスト計測 `school-rg-playtest-v1` とは分離しています。フォーマットは `{ formatVersion: 1, entries: [...] }` で、保存済みのランIDをキーに再読込や結果画面の再表示で二重登録しません。旧セーブにランIDがなければ読込時に生成し、終了済みセーブを開いたときに履歴へ登録します。

履歴を読めないときは元データを上書きせず、画面にエラーを表示します。保存に失敗したときも表示し、その画面上の記録は再読込後に残らない可能性を伝えます。履歴はこの端末・このブラウザ内だけにあり、同期や自動エクスポートはありません。

数値スコアと所要時間の正式な算定は未確定です。任意計測の実操作時間を通常の履歴へ流用せず、設計判断は [#151](https://github.com/sato0825/school-rg/issues/151) で追跡します。
