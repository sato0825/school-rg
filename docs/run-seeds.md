# ランのシード

新規ランで部活を選んだ時に、ブラウザの `crypto.getRandomValues` から 32 bit のシードを一つ生成する。マップや報酬などのドメイン処理はそのシードから決定的に進む。タイトル表示用の仮セッションと保存済みランの再開では新しい乱数を消費しない。マップ画面にシードを表示し、保存データにも保持する。

開発サーバーでは `?seed=42` のように 0〜4294967295 の整数を指定すると、新規ランでその値を使う。E2Eはこの経路で再現性を維持する。符号、小数、先頭ゼロ、範囲外、数字以外は無効として通常の乱数生成に戻す。公開ビルドではクエリの `seed` を無視する。

シードを入力して再挑戦する正式なUIは未実装。再現用クエリは開発用であり、ユーザー向けの共有機能として扱わない。
