# Issue #219 戦闘効果音のレビュー

候補試聴: [7音色・各0.58秒間隔のWAV](previews/issue219-cues-v1.wav)。`node scripts/render-audio-cues.mjs <Vite URL> <未作成のWAVパス>` で、ランタイムと同じWeb Audio実装から再生成する。実装パラメータは `src/ui/audio.ts` に固定し、乱数テクスチャも音色ごとに決定的に生成する。

| 順番 | 音 | 役割 |
| --- | --- | --- |
| 1 | card | 短い上昇音と紙を払う質感でカード発動を示す |
| 2 | enemy | 低い下降音で敵行動の予告を示す |
| 3 | hit | 低い衝撃音でHP減少を示す |
| 4 | block | 硬く短い反応で防御の増減を示す |
| 5 | status | 柔らかい2段音で強化・弱体化・回復を示す |
| 6 | win | 短い3音の上昇で勝利を示す |
| 7 | lose | 短い下降2音で敗北を示す |

同一アクションに複数の結果がある場合、結果音はダメージ→防御→状態の優先順位で1種類だけ鳴らす。カードの発動音から結果音を0.07秒ずらし、入力と変化の因果を保つ。低刺激表示では各声のピークを40%にし、ミュートでは発音しない。音は表示の補助であり、HPゲージ・数値・結果バッジなどの視覚情報は維持する。

ChromiumのOfflineAudioContextで7音すべての非無音、0.15未満のピーク、低刺激時の音量減少、カード＋結果の同時発音を確認。これは波形上の検査であり、実機スピーカー・ヘッドフォンでの聴感品質、iPad/Windowsの出力、長時間の感覚負荷は未検証。最終サウンドデザインは #29 の品質ゲートで扱う。
