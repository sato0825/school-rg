# 科学部の条件構築（Issue #74）

科学部の12枚と初期装備は仮カードとして実装済み。`sample` → `reaction` / `test tube` は毒、`observe` / `catalyst` → `assay` は弱体を条件にする。`catalyst` は毒と弱体を同時に仕込むため、次の一手を選べる。カード名・効果量・出現率は正式承認済みではない。

今回 `assay` の条件を毒から弱体へ変更した。以前は3枚の条件攻撃がすべて毒を参照し、弱体を仕込む攻撃上の意味が重複していた。共通の `damage_if_status` 効果を使い、個別の例外コードは追加していない。

テストでは仮の10秒ターンで1文字450msの入力を与える。`catalyst` 8文字と `assay` 5文字は5.85秒で入力でき、残り4.15秒となる。これは実プレイヤーの速度分布や約60分ランのバランス合格を示さない。毒だけでは `assay` の条件を満たさず、弱体と毒を仕込んだ場合に条件値となること、アップグレード値、効果順、保存・再開後の残り時間を確認する。

残課題は実プレイヤーによる複数速度帯・敵編成・報酬選択での検証、カード名/数値の確定、#29 に沿う科学部キャラの基準画・3ポーズ・編集可能原本の採用である。#74 の全DoDはこれらが揃うまで未完とする。
