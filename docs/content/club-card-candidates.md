# 固有カード候補の追加（#122）

各部活の固有プールを6枚から8枚に増やした。初期デッキ10枚と共有基本24枚は変更しない。追加語と効果量はすべて仮値であり、#31 のデッキ完成、#29 の人物アート採用、#68 の約60分バランス判定を意味しない。

## Issue #148: 固有報酬候補の追加

各部活に4枚ずつ足し、固有報酬プールを12枚にした。初期デッキ、共有基本カード、既存IDは変更しない。文芸は手札を削ってドロー、捨て札回収、短い連鎖入力、複数対象を選べる。科学はデバフ解除、防御の継続、毒の有無で変わる攻撃順、弱体化と毒の組合せを増やす。剣道は防御と残り時間、攻防一体、継続強化、複数敵への守備を増やす。軽音はドローと時間、多段入力、長い語での時間補充、使い切りの全体攻撃を追加する。美術は継続防御、手札複製、手札除外、全体攻撃と継続防御を増やす。

語と数値は `src/content/*-cards.ts` の差し替え可能な仮値。報酬の正式なレアリティ・出現率、語長と時間の釣り合い、カード選択の面白さは #68 の実プレイで判断する。20枚の追加と自動完走だけで完成コンテンツとはしない。

手札が6枚以上になった狭い戦闘画面では、カードの横送り案内を表示し、入力ごとの再描画でもスクロール位置を保持する。5部活で追加カードを横へ送って確認し、カード名を直接入力して効果・保存状態をブラウザーで検査する。

| 部活 | 追加語 | 構築上の狙い |
| --- | --- | --- |
| 文芸 | `aside`, `footnote` | 短い攻撃からの2枚ドローと、防御しながらの2枚ドロー。手札が増えても入力時間は増えない。 |
| 科学 | `catalyst`, `assay` | 毒と弱体を一手で仕込み、`assay` は弱体の有無で攻撃値が変わる。毒の条件攻撃は `reaction` と `test tube` が担当する。 |
| 剣道 | `sweep`, `breath` | 複数敵に対する攻撃と防御、反撃を備える。 |
| 軽音 | `bridge`, `refrain` | 長めの入力語を時間加算で補い、ドローや全体攻撃へつなぐ。 |
| 美術 | `wash`, `layer` | 全体攻撃からのドローと、保持可能な継続防御を選ぶ。 |

カードID、語、効果は部活ごとの `src/content/*-cards.ts` にあり、共通のカード効果エンジンへ渡す。報酬プールはカード定義から生成されるため追加IDを別表に重複記載しない。正式な出現率、カード総量、語長と制限時間の釣り合い、敵編成ごとの有効性は #31/#68 で実操作を記録して調整する。

狭幅画面の初回証跡 `issue122-bridge-narrow-20261031.png` は保存復帰直後で時計が一時停止しており、入力操作の検証が失敗した。テストで「再開」を押してから発動するよう修正し、再検証時の証跡を `issue122-bridge-narrow-v2-20261031.png` として別保存する。
