# 美術部デッキの現状（Issue #77）

現行の12枚、初期装備、カード名と数値は制作中の候補であり、約60分ランのバランス検証と #29 のアート採用を終えた確定仕様ではない。

- 初期デッキの `sketch` は攻撃とドロー、`frame` は保持する防御、`paint` は手札の複製、`erase` は手札の除外とドローを担う。短い語を連続入力して手札を入れ替える部活とは異なり、次ターンに残す札と複製元を選ぶ。
- 報酬プールの `redraw` は選択した札を全体攻撃 `mural` に変化させる。`layer`、`primer`、`mural` は継続防御を積む。複数敵への効果は `mural`、`wash`、`triptych` で持つ。
- 手札複製の新規インスタンスと変化後のカードは、山札・手札・捨て札・除外・解決中のうち一つにだけ存在し、セーブ復元で同じIDとカード定義を保つ必要がある。今回の回帰は保持した複製札のターン越えと、変化後の全体攻撃・継続防御を確認する。

既存の5部活×通常3 Act直接入力E2Eは美術部も対象に含む。美術固有の `paint` はPC幅とiPad相当幅で直接入力・対象選択・セーブ復元を追加確認する。実機iPadでの操作、全カードを使った約60分の構築判断、#29の編集可能原本と動きの品質審査は残る。
