# 軽音部の時間と連続使用（Issue #76）

この個票と数値は候補仕様です。カード12枚、初期デッキ10枚（固有4枚）、開始レリック「部室のメトロノーム」と時間ポーションは既存実装を使用します。約60分ランでの時間損益とカード報酬の強さは #68、人物アートの正式採用と編集可能原本は #29 の未完事項です。

## プレイ判断

- `tempo` は5字の入力後に2秒を加え、1枚引く。引いた語を続けて打つ余地を作る。
- `sync` は4字の入力後に2枚引き、1秒を加える。追加ドローだけでは時計を戻せないため、次の語を打つ判断が必要になる。
- `beat` は4字で同じ敵を3回攻撃し、時間は加えない。敵の防御や反撃とhit順が関係する。
- 時間加算は入力前の支払いではなく、カード発動後に適用される。残り時間が尽きればカードは発動せず、未使用の手札はターン終了規則に従う。
- 暫定の1ターン上限は30秒。複数カード・メトロノーム・ポーションで加算しても超過分は蓄積しない。敵の独立時計や別のリズム入力はない。

## 検証と残件

統合テストでは仮の1キー450msで `tempo → sync → beat` を直接入力し、時間、ドロー、3hit、捨て札、途中保存・復元を確認する。これは実プレイヤーの打鍵速度を測定した結果ではない。PCとiPadでの実操作、通常ラン約60分での強さ、全12枚の構築判断、5人の最終アートとの統一は継続検証する。
