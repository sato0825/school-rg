# Issue #144 遭遇候補の一巡抽選

各Actの通常戦闘・強敵・ボス候補は、それぞれ独立した一巡単位で選ぶ。未選出候補から現在のシードの乱数で抽選し、全候補が出た次の抽選から新しい一巡を始める。単体敵は敵ID、複数敵編成は編成IDを候補として数える。イベント戦闘は遭遇表の抽選に含めない。

この方針は `demoEncounterTable.selectionPolicy = "cycle"` に隔離した #68 の暫定コンテンツ設定。注入する従来型の遭遇プールと `selectionPolicy = "uniform"` は復元抽選のまま使える。正式な候補量、出現率、難度、所要時間は実プレイ結果を踏まえて #68 で判断する。

選出済み候補IDはランのセッションにAct・種別別で保存する。保存形式1の古いデータに履歴がなければ空の履歴として読み込み、既存のセーブを破棄しない。戦闘効果、敵Intent、カード入力、マップ生成は変更しない。

検証は3 Actそれぞれの通常候補一巡、複数敵編成の順序、同一シード、保存復元、旧保存形式を扱う。5部活で通常マップをタイピングして3 Actを完走するブラウザー検査も行う。自動完走は約60分の実プレイ計測の代わりにしない。
