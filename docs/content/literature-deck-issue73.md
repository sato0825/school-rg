# 文芸部の固有デッキ（Issue #73）

この文書は実装中の候補仕様を記録する。カード名・効果量・報酬分布は暫定値で、#68 の約60分ランの実プレイによる調整対象。人物アートの正式採用は #29 の品質ゲート対象である。

## 入力と構築の判断

- 初期デッキ10枚のうち4枚が文芸固有。報酬プールには固有12枚と共通24枚がある。
- `jot`・`leaf` など短い語からカードを引き、残り時間を使って次の語を入力する。ドロー自体は入力時間を増やさない。
- `reread` は捨て札から選んだ1枚を手札へ戻してから防御を得る。捨て札がないと発動できず、最初に別のカードを使う判断が必要。
- `edit` は手札の別の1枚を選んで除外してから2枚引く。手札に対象がない場合は発動できない。対象の選択にもターン時間が流れる。
- `bookmark` は捨て札から1枚を回収して時間を加える。最初の手札に現れ、捨て札がなくてもターン終了時に保持するため、次ターン以降に使える。保持はカードの効果表示と読み上げ名へ含める。

## 検証と残件

`tests/integration/literature.test.ts` は語を直接入力し、回収→防御、除外→ドロー、保持→時間切れ→保存復元、山札・手札・捨て札・除外の整合を確認する。実画面のPC/iPad操作、3 Actの文芸固有カード使用、#29に沿った原本・動作素材・人物同一性、約60分の調整は別途記録する。
