# 剣道部の固有デッキ（Issue #75）

この文書は実装中の候補仕様を記録する。固有カード名と効果量、初期デッキ、報酬分布は暫定値で、#68 の約60分ランの実プレイによる調整対象。キャラクター画像の正式採用は #29 の制作ゲート対象である。

## 入力と判断

- 初期デッキ10枚のうち4枚が剣道固有。固有報酬プールは12枚で、共通基本24枚とも組み合わせる。
- `parry` はブロックと、この敵フェーズに受けた攻撃へ返す反撃を備える。初期装備「竹刀の握り」はターン開始時にも反撃を加える。
- 攻撃Intentを見たときは防御後の被弾と反撃を計算し、防御Intentを見たときは攻撃を選ぶ判断が生じる。`thrust` は防御を付けない単体攻撃である。
- `sweep` は複数敵を同じ効果順で攻撃してから自身にブロックを与える。対象の数にかかわらず、入力する語は一つである。
- `final cut` は対象のHPが半分以下なら威力が上がる単体攻撃。条件は入力の終了時に解決する。敵のHP、ブロック、残り時間を見て使う。

## 検証と残件

`tests/integration/kendo.test.ts` は直接キー入力、予告Intentごとの被弾差、2体・多段攻撃での反撃順、倒された攻撃元の後続ヒット停止、全体攻撃、保存復元を確認する。`tests/e2e/app.spec.ts` の5部活共通の通常12階×3 Act試験は、剣道のカード名を直接入力して3 Actを完走し、途中で保存再読込する。これは自動化されたPCブラウザー確認であり、iPad実機QAや約60分の実プレイバランスを意味しない。#29の編集可能原本、3ポーズ同一性・動作審査も残る。
