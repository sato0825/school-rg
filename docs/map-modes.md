# ランのマップ設定（Issue #100）

通常起動はドメインの `DEFAULT_MAP_OPTIONS` を使い、3 Actそれぞれ12階層とボスを持つ。階層数、レーン数、ノード種別の重みは現時点の仮値で、約60分を測定して確定する。マップはシードから決定的に生成され、セーブには生成済みノード全体が保存される。URLを変えて再開しても、途中のランの階層数は変わらない。

開発・E2E用の `?shortRun=1` は2階層/Actの短縮マップを新規生成する。通常の新規ランと明示的に分離し、短縮ランの完走時間を60分の受入値に使わない。両設定ともカード名の直接入力と同じ戦闘システムを使う。

通常ランの画面と到達可能性、実際の所要時間・選択の密度は #68 で継続検証する。敵候補、カード報酬、イベント等の内容量も未完成で、階層数だけでは完成ランにならない。
