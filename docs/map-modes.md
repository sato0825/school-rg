# ランのマップ設定（Issue #100）

通常起動はドメインの `DEFAULT_MAP_OPTIONS` を使い、3 Actそれぞれ12階層とボスを持つ。階層数、レーン数、ノード種別の重みは現時点の仮値で、約60分を測定して確定する。マップはシードから決定的に生成され、セーブには生成済みノード全体が保存される。URLを変えて再開しても、途中のランの階層数は変わらない。

開発・E2E用の `?shortRun=1` は開発サーバーでのみ2階層/Actの短縮マップを新規生成する。本番ビルドではこのパラメータを無視する。通常の新規ランと明示的に分離し、短縮ランの完走時間を60分の受入値に使わない。両設定ともカード名の直接入力と同じ戦闘システムを使う。

通常ランの画面と到達可能性、実際の所要時間・選択の密度は #68 で継続検証する。敵候補、カード報酬、イベント等の内容量も未完成で、階層数だけでは完成ランにならない。

## 経路の密度（Issue #181）

各Actの開始地点から1階の4地点は選択できる。通常階の間は各地点に同じ列の道を1本ずつ確保し、隣の列へ進める分岐を階ごとに1本だけ追加する。各階は5本の道となり、以前の8本の交差する道より選択経路を追いやすい。全地点が開始から到達でき、最終ボスへ進める。分岐数は選択の密度とランの所要時間の検証前の仮値であり、難度の確定仕様ではない。生成済みマップはセーブに保持されるため、既存ランの経路は変わらない。

シード42の通常ランで文芸部を選び、[PC 1440×900](art/previews/issue181-map-1440.png)と[iPad幅 1024×768](art/previews/issue181-map-1024.png)を確認した。選択可能な1階4地点と、2階以降の疎な道が表示される。部活選択後の画面位置も先頭へ戻る。

## 実画面

ブラウザで通常起動し、文芸部を選択した。Act 1にはSTART、12階層×4レーン、13階のボスが生成され、[1440×900](run/previews/issue100-full-map-desktop-retry1-20261031.png)と[390×844](run/previews/issue100-full-map-narrow-retry1-20261031.png)で表示した。縦方向はマップ欄内でスクロールできる。両幅で1階の強敵を選択し、[デスクトップ](run/previews/issue100-full-map-desktop-after-select-20261031.png)・[狭幅](run/previews/issue100-full-map-narrow-after-select-20261031.png)とも戦闘画面へ移った。経路全体の手動完走と所要時間は未確認。
