# 通常3 ActのUI経路調査（#232、2026-10-31）

親: [#68](https://github.com/sato0825/school-rg/issues/68)。対象コード: `origin/main` 425a559（#203・#210・#204統合後、#211未統合）。これは**自動操作による画面経路調査**であり、人間の約60分プレイテストではない。

## 操作と記録の条件

- `?playtest=1&seed=<値>`、`shortRun` なしで起動。Act 1 のボス階が13であることを実行時に確認。Chromium 1440×900で、5部活はシード42の安全経路、文芸部と科学部は追加の経路/シードで操作した。
- ラン開始・部活選択、接続されたノードの選択、イベント・ショップ・休憩・宝箱、カード名のキー入力イベント、ポーション、戦闘報酬を**実際の画面経路**で通した。`safe` は休憩/イベント等を優先し、`combat` はHPが23を超える間、選択可能な通常戦を優先した。人工の戦闘状態・報酬・マップを注入していない。
- Playwrightの仮時計でターン終了を進め、戦闘カードは固定優先順で自動入力した。記録の`wallMs`は自動化の処理時間、`activeMs`は仮時計を含むゲーム内計測。**どちらも人間の所要時間ではなく、約60分目標の証拠には使えない**。
- `scripts/probe-full-run.mjs` が各画面のAct/階/種別、敵編成、イベントID、実際に表示された背景URLとオプトイン計測を保存する。初回試行はAct 2・10Fで勝利遷移中に入力欄を待って停止したため、`issue232-20261031-a`として原文を保全。仮時計で遷移を進める処理を追加後、下記8件は全て結果画面まで到達した。失敗を成功に混ぜていない。

訪問42地点は各Actの開始・通常12階・ボスを含む（42=3×14）。同じseed42の`safe`5件はマップと選択方針を共有するため**独立した5つの経路標本ではない**。敵の抽選・イベントの提示は部活ごとのゲーム状態で変わった。各Actの背景は前半1枚、後半1枚。例えばseed42の文芸`safe`ではAct 1の2枚が9/4地点、Act 2が10/4、Act 3が11/3地点に表示された（Act 1の開始地点は画面記録対象外）。全ランで最大11地点が同一背景で、場所の反復は明確だった。

`combat`方針で科学部・seed13579は戦闘32回のうち同Act内で同じ敵編成との再遭遇が14回（43.8%）。候補を各Act5種に増やした後でも、戦闘を選ぶ経路では反復が多い。一方`safe`5部活・seed42は各19戦で再遭遇1回だった。これは経路方針に依存する初回診断であり、全プレイヤーの平均反復率とは扱わない。

イベントは全ランで2〜7回。Act 3では同一イベントが4回中2回提示された例がある。ショップ・宝箱・レリック・ポーションの**提示数・購入/取得/消費・重複率は#211未統合のため未測定**。本調査の画面記録に一部の報酬文言はあるが、集計済みの完全な露出データとはみなさない。

## #68と#31に残る受入

5部活の通常3 Actを自動操作で完走した事実は、UI経路・保存・戦闘の回帰証拠に限る。プレイヤー自身が部活ごとのデッキ判断を行い、PCキーボードとiPad実機で3 Actを操作した証拠ではない。難度、離脱率、主観的な反復感、約60分の距離は未検証。`activeMs`は仮時計を含むため集計の所要時間へ入れない。

次は#211統合後に商品・報酬等の露出を再計測し、複数シード/経路の人間の実操作記録を集める。背景は各Act2枚では通常14地点に対して場所の変化が少なく、追加の独立した校内シーンを子Issueで設計する。戦闘を積極的に選ぶ経路では同編成再遭遇が多いため、既存31敵の組み合わせ・配置規則を別Issueで検討する。新しい数値は#68の仮値として扱い、アートの最終品質は#29に従う。
