# 継続制作ゲート v0.1

親: [#29](https://github.com/sato0825/school-rg/issues/29)。この文書は素材の制作・採否手順であり、候補画像そのものの承認ではありません。

## 固定する入力

1. 人物IDと部活ID、基準画、顔・体格・髪・制服・小物の不変条件を決める。現在の真面目な子の年齢感と画風の方向は `reference/serious-student-approved-direction.png` を参照する。正式な人物設定は #31 で追跡する。
2. `asset-register.json` に素材ID、参照ID、版、生成指示ファイル、出力SHA-256、寸法、透過方針、出典、採否を記録する。新しい制作回では同じ入力を使い、変更点を明記して別IDで保存する。既存原本を上書きしない。
3. 表情・待機・発動・被弾を同じ編集可能原本から作り、各ポーズの部位、接地位置、頭身、カメラ方向、輪郭線、陰影を固定する。透過PNGは配布用派生物であり、原本の代わりにしない。

## 検査

- `npm run art:review-board` は台帳から [同条件比較ボード](review-board.html)を再生成する。5人の基準画と待機・発動・被弾の全版を固定サイズと同じ背景で並べ、SHAの先頭、候補状態、編集可能原本の有無、[人物ごとの判定記録](review-decisions.json)を表示する。新しい候補を台帳へ追記した後は再生成し、旧版を消さずに差を審査する。ボードの生成は画質の合否を判定しない。判定記録の `pending` を変えるには理由を個別レビュー文書へ残す。

- `npm run check:art`: ファイル存在、SHA、PNG寸法・色形式、実際の透過値、参照と指示の存在、同一人物のキャンバス寸法を検査する。`approved-runtime` に進める場合は編集可能原本、レビュー記録、待機・発動・被弾の3状態が必要。
- 採用する透過素材は不透明に見える領域（alpha 16以上）の外接矩形とキャンバス端の間に、短辺の1％以上かつ最低8pxの余白を必要とする。候補段階では外接矩形を出力し、既存候補を自動的に採用・不採用へ振り分けない。SVGを編集可能原本として指定する場合は、台帳に `editableParts` として少なくとも2つの部位IDを記載し、各部位にベクター図形を含む名前付きグループを置く。埋め込み画像、外部参照、スクリプトを含むSVGは採用ゲートを通らない。Krita/PSD/Asepriteの原本は存在だけを機械検査し、レイヤーの実体は制作レビューで確認する。
- 人が基準画と3ポーズを並べ、年齢感、同一人物に見えるか、顔・線・影・服・小物、手足の形、透過の縁、接地位置を判断する。不一致は修正または不採用として記録する。自動検査の成功を画質合格としない。
- 実際の戦闘画面で、広い背景と独立したキャラ層の上に3状態を置き、入力完了、敵攻撃、時計、Intentとの同期を確認する。デスクトップと狭い画面で、味方・敵・カード・入力帯が重ならないか確認する。
- 別制作回に同じ不変条件を与え、再現した絵を既存基準画・素材と並べて比較する。顔や衣装が変わる場合は単一の良い画像があってもゲートを通さない。

## 現在の判定境界

`candidates/serious-student-*-candidate-v1.png` は3状態の比較候補です。編集可能原本と中間フレームがなく、戦闘画面へは採用していません。3枚の生成指示とSHAは保存済みですが、同一人物の継続制作とアニメーション品質は未証明です。次は編集可能な部位別モデルと実ゲーム上の切替・補間を作り、レビューを行います。
