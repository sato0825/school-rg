# Issue #134 校舎ルート画面レビュー

## 画面

- [1280 × 844 のマップ](previews/issue134-map-desktop-20261031.png)
- [390 × 844 のマップ](previews/issue134-map-narrow-20261031.png)

両画面は `shortRun=1&seed=42` で文芸部を選択し、画像を読み込んでから Playwright Chromium で撮影した。横方向の文書幅はそれぞれ 1280px と 390px。ルートは既存の `MapNode.nextIds` から描画し、現在地点から選べる線をローズ色、過去の線を青緑、先の線を淡い破線にした。円形トークンの色と記号で地点種別を区別する。

マップ上部には選択中の部活人物、Act、HP、所持金、デッキ枚数を表示する。人物画像は #29 の制作候補で、編集可能原本と最終画風の受入を示すものではない。実機での表示確認は未実施。

## 検証範囲

追加 E2E は表示された接続線をセーブ中のマップデータと照合し、選択可能な線と地点の一致、390px の横はみ出し、キーボードでの地点選択を確認する。既存 E2E は同一シードの 3 Act 進行と Act 境界を含む。描画関数はマップ生成、到達可能性、セーブ形式を変更しない。
