# 戦闘HUDと敵ターンの表示確認（Issue #166）

対象: 1440×900 / 390×844、科学部、Act 1の答案の切れ端。画像はPlaywrightで同じ戦闘を描画して保存した自動操作の証拠です。人の手によるゲーム全体の受け入れは別途必要です。

## 変更の狙い

- 操作欄の内容でステージ高さが変わり、敵ターン境界で立ち絵と背景が上下に動く構造を固定した。
- プレイヤーのHP・ブロック・状態・レリック、戦闘ログと遊び方の操作をヘッダへ移し、舞台上の箱と入力欄横の操作を減らした。
- 敵行動の中央バナーを外し、敵と味方を隠さず、状況文と入力停止でフェーズを伝える。
- 捨て札回収・状態解除の選択欄は、対応カードと対象がある場合だけ出す。ポーションの待機説明と空き表示も省いた。
