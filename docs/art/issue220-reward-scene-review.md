# Issue #220 — 戦闘報酬の場面連続性

## 表示の判断

- 戦闘と同じ現在地点の背景画像を使い、味方と最後に倒した敵を装飾層として残す。敵は薄く表示し、選択対象と混同させない。
- 半透明の紙面に報酬カード3枚を置き、取得・スキップを主操作にする。戦闘中の入力欄と時計は報酬画面に持ち込まない。
- ヘッダには現在地点、HPゲージ、所持金、デッキ枚数を置く。ゲームタイトルは出さない。
- 人物画像は読み上げ上の操作対象にせず、カードと操作ボタンの意味を短い文字で残す。
