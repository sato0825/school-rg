# Issue #234 キャラクター動作レビュー

## 表示の時間軸

カード名の入力完了から約380msだけ発動ポーズを重ねる。攻撃は敵側へ短く踏み込み、支援はその場で上へ動く。敵のIntent解決でHPを失った場合は約420msだけ被弾ポーズへ移る。待機画像は動作中も背後にあり、入力やタイマー表示によるDOM再描画は開始時刻から負のanimation-delayを復元する。接地影のみ人物に追従し、ステージ・ヘッダ・入力帯の座標は固定する。

低刺激とOSの動き軽減では重ね画像を隠して発動/被弾の静止ポーズを示し、結果の数値バッジを保つ。カード・敵のルール、タイマー、保存形式は変更しない。

## 検証

- lint、型検査、ビルド成功。
- 直接タイピング・敵Intent・再描画時の位相・ステージ/人物枠の不変・低刺激/OS動き軽減の対象E2E 8/8成功。
- 1024pxと1440pxの攻撃・支援・被弾画面を目視し、入力帯・敵HUDとの重なりなし。55msの重ねでは腕の線が一瞬重なるが、約380ms内に解消する。
- 連続動画3本の生成テストは3/3成功。1024幅の標準動画はChromeで再生し、ステージと入力帯が人物の動きに追従して揺れないことを確認した。録画には既存画面の右側の空き領域が映る。1440幅と低刺激動画の連続した目視判定は未完。
