# 候補カード絵の配布用派生画像（Issue #283）

`issue255-config.json` は Wave 1 のカード候補5 IDについて、採用候補の版と焦点座標を固定する。元画像は `docs/art/production/issue255/wave1-assets.json` が参照するPNGで、書き換えない。`KEN-001` は旧 v1 を残し、選択のみ v2 にする。#269 以降の候補は別の設定ファイルと出力先を用意して追加できる。

```sh
node scripts/art-derivatives.mjs build docs/art/production/derivatives/issue255-config.json
node scripts/art-derivatives.mjs verify docs/art/production/derivatives/issue255-config.json
```

ビルドは既存ファイルの内容が異なる場合に停止し、上書きしない。検証は元PNGのSHA・寸法、派生画像のバイト一致・寸法、台帳の一致を再生成で照合する。エンコーダの出力が変わるため、台帳に記録された ImageMagick 7.1.2-25 と同じ版での照合を基準とする。版が違う環境では既存ファイルのSHAと寸法を先に確認し、再生成結果の違いはレビューする。焦点を変える場合は新しい設定ID・出力先・台帳を作り、旧版を保持する。

| 用途 | 1倍 | 2倍 | 画面での確認点 |
| --- | ---: | ---: | --- |
| 手札 | 160×72 | 320×144 | 小表示で主題が判別できるか |
| 報酬 | 256×96 | 512×192 | 選択肢間で焦点が揃うか |
| 詳細 | 768×512 | 1536×1024 | 細部と圧縮アーティファクト |

比較用の `review-v2.html` は元PNGと1倍・2倍を同じCSS表示寸法で並べる。詳細欄のみ画面に収まる384×256 CSS pxで縮小表示する。旧 `review.html` は表示寸法ラベルに誤りがあったため保持したまま参照対象から外した。ブラウザで開いて、PCとiPad相当の表示幅で主題・切れ・画風の差を確認する。今回の5枚・30出力の合計は 448.1 KiB、元PNG5枚は約8.7 MiB。個別の容量、SHA、焦点、切り取り位置は `issue255-manifest.json` に記録される。ブラウザ表示と絵としての採否は別途判定する。

全元画像は編集可能原本が未登録で、権利・画風レビューも pending のままである。この派生工程は候補画像の正式採用を意味しない。ゲームUIの参照先も変更していない。
