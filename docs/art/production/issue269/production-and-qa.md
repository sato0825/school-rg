# #269 カード絵 第二波 — 候補制作と実寸QA

## 対象と位置付け

Issue #248 の制作体系に従う #255 の後続バッチ。文学、科学、剣道、音楽、美術から各2枚、計10枚の未制作IDに初稿候補を作った。正式採用、カードの正式レアリティ、全カタログ完成を意味しない。ゲームデータと効果は変更していない。

画像の共通指定は3:2、寒色、薄い紺輪郭、静かな余白、主題を中央約52%幅／55%高に収めること。画像の中にカード枠、文字、レアリティを焼き込まない。各原本、生成プロンプト、SHA-256、ID、版、採否状態を `wave2-assets*.json` と `wave2-prompts.json` に保存した。生成シードと編集可能な手描き原本は存在せず `null`、権利・美術監修は未了と明記した。

## 実寸確認

- `qa-board.html` をブラウザで表示し、iPad相当1024pxとPC相当1440pxのスクリーンショットを保存。
- iPad手札 133×180px、絵窓113×57px、効果11px。PC手札166×204px、絵窓144×67px、効果12px。
- iPad報酬165×220px、絵窓135×91px、効果12px。PC報酬220×270px、絵窓190×100px、効果13px。
- 同じボード上で48×48pxサムネイルも確認。全10枚で主題がフレームに収まり、主要な物体のシルエットを識別できた。画像の欠落は0件、横スクロールなし。
- 絵だけでは効果の数値・処理順序は読めないため、効果文を残した。これは素材と仮カード枠の確認であり、実戦闘UIでの可読性合格ではない。

## 視覚監修で残る判断

- LIT-005は周囲の装飾が多く、他カードより強い印象。原本の密度を揃える描き直し候補。
- SCI-009は円形の透明蓋が背景に近く、48pxで「解除」まで連想するには弱い。主題の輪郭を強める候補。
- ART-005の画布内の建物は学校の場面として不明瞭。別の塗り直し場面を検討。
- KEN-011の上向き矢印は効果記号に近く、レアリティではないが他素材と演出文法を揃える必要がある。
- 旧#255素材を含む全カタログの線密度、彩度、絵窓での主題サイズを横並び監修する必要がある。今回の10枚を正式採用しない。
- #247で正式レアリティと配分が未決定。画像の仕上げとカード枠の配色は決定後に別管理する。

## 在庫

ソースの84カード・11レリック・6ポーション＝101件を `scripts/build-art-inventory.mjs` で棚卸し。今回の10IDは既存候補と重複しない。候補参照を持つIDは29件、候補なし72件、正式採用0件。次の制作バッチにまだ72件と監修・採用工程が残る。

## 初稿4枚の再監修（v2）

`qa-revision-board.html` と `qa-revision-ipad-1024-v1.png` で、各v1/v2を113×57pxの手札絵窓と48×48pxで横並び比較した。画像欠落0、横溢れ0。各v1はこのサイズでの使用候補から外し `superseded-candidate` とした。v2は構図の次段階候補 `preferred-draft` とし、正式採用ではない。

| ID | v1で確認した問題 | v2で改善した点 | 次の画作りで残る点 |
| --- | --- | --- | --- |
| LIT-005 | 本の装飾と背景が多く、他候補より視線を奪う | 閉じた本と戻るしおりの形に集中 | v2は他の6枚より淡泊。紙と輪郭の質感を揃える |
| SCI-009 | 透明の蓋が背景に埋もれる | 紺の円形リムと綿棒が48pxでも分離する | 「防御」と「解除」の関係は効果文で補う |
| KEN-011 | 上向き矢印が汎用の数値アイコンに見える | 防具と同心円に置き換えた | 持続筋力の意味は絵だけでは弱い。効果表示との対応を確認 |
| ART-005 | 画布に描かれた城が学校の文脈から外れる | 抽象的な塗り直しを一筆で示す | 平坦になったため、他カードの手描き感へ寄せる |

初稿と改稿の両方を原本・SHA・プロンプト付きで保全した。#261の本編手札が確定したら、候補だけの静止ボードではなく実戦闘画面で再監査する。

### 画風調整 v3

上表のLIT-005、SCI-009、ART-005はv2の構図を保ってv1系列の筆致を参照したv3も作成。`qa-board-harmonized.html` / `qa-harmonized-ipad-1024-v1.png` に、v3とKEN-011 v2をほかの6枚と同時に配置した。iPad手札113×57px、報酬135×91px、48pxサムネイルで主題は残り、画像欠落0、横溢れ0。v3はv2より周囲の候補と塗りの密度が近いので、3IDの優先候補をv3へ移した。v2は構図検討資料として残し `superseded-candidate`、v3は `preferred-draft` とした。正式採用0件は変わらない。

ART-005 v3は青い筆跡の広がりがまだ強く、#242/#261の実戦闘背景の上で主題が埋もれないか再確認が必要。SCI-009 v3の円は明確だが、効果の「弱体解除」は絵単体で厳密には伝わらない。効果の短文と状態アイコンとの併記が必要。
