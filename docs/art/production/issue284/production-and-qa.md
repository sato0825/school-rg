## 原本と版

`prompts.json` と `revision-prompts.json` が生成指示の原文。`assets-batch-a.json`、`assets-batch-b.json`、`revision-assets.json` が各ID・版・原本パス・SHA-256・寸法・採否状態を記録する。画像ファイルを変更する場合は上書きせず新版を追加する。生成ツールはseedと編集可能ソースを提供していないので、`seed` と `editableSource` は `null`。原本はリポジトリ内に保存済み。

Boost v1は48pxで丸時計に見え、レリックの時計類と衝突するため候補から外した。Mural v1は48pxで風景になり、壁画という物体が見えないため候補から外した。v2はそれぞれ四角タイマー＋矢印、壁面パネル＋塗り面に修正した。両v1は削除せず `superseded-candidate` として保全した。

## 実寸QA

`node docs/art/production/issue284/qa-board.mjs` で1024・1440pxボードを生成した。静止ボードの手札外寸は140×160／170×160px、絵の表示窓は112×57／145×57px（CSSのclient寸法は枠線を除く）。報酬は165×220／220×270px、48px中央クロップも並置した。`qa-board-1024-v1.png` と `qa-board-1440-v1.png` は初稿、`qa-board-1024-v2.png` と `qa-board-1440-v2.png` は改稿後の記録。

- 全画像のロード、手札・報酬の効果文字がカード内に収まること、横スクロールなしを機械的に確認。
- 目視では10 IDの主題物体を48pxとiPad手札で識別できる。Riposteの往復軌道、Muralの防御の細部、Crescendoの時間追加は縮小絵だけでは完全に読めないため、効果文との併用が必要。
- 本編画面の背景、演出、他カードとの隣接、色覚特性、感覚過敏設定での適合は未確認。静止ボード合格をゲーム画面の合格とはしない。
