# #343 カード候補の並置監査

対象は #335 のランタイムに接続された56/84候補。`contact-sheet.mjs` が1024/1440pxの手札・報酬窓で56画像を全ロードし、共通と5部活を並べた。#327の実ゲーム剣道部1024px手札も参照した。担当者の静止画目視であり、ユーザー受入やゲーム内動作の合格ではない。#341の後続10候補はこの監査対象にまだ含まれない。

## 画風ゲート

同じ手札の5枚を見て、(1)輪郭の太さと有無、(2)影と立体感、(3)彩度、(4)紙地、(5)物体の視点、(6)主題の占有率と余白を比較する。単体の48px判別に通っても、写真/商品画像・3D展示風が混じれば不合格。絵を隠した時はカード名と正確な効果が残り、文字を隠した時は行為と対象の方向が残ることも別ゲートにする。

文芸/音楽/美術は大半が青灰紙地・淡い影・道具中心の絵で揃う。ただし「統一されている」の判定を正式採用と扱わない。LIT-004 は #329 runtime で写真調v1から #296 紙地ガッシュv3へ交換済みであり、#327の指摘は古い画面の状態を示す。

剣道部のP0三枚とKEN-004、BASE-017、BASE-023を原本・版・SHAを残して改稿した。`contact-hand/reward-*-v1.png` は旧版、`v3.png` は改稿版の並置。v2接触シートは改稿後画像を表示するがラベルだけ旧ファイル名だったため、v3でラベルを修正した。1024/1440の手札/報酬で56画像のロードを確認。写真風の室内/床反射はP0三枚とBASE-023から除去できた。BASE-017の広告アイコン風の紫矢印も除去し、KEN-004は二打を保持したまま部屋背景を除去した。これは担当者の静止画判定であり、正式採用ではない。

`meaning-gate.mjs` では改稿優先6件の手札112×57px・中央48px・グレースケール・絵のみ/文字のみを並置し、48/48画像のロードを確認した。色を消しても剣道面/足運び/立てた竹刀/二打、丸いストップウォッチ/台形の卓上タイマーは形で異なる。絵のみで正確な防御量・打数・時間秒数・持続効果は確定しないため、文字と実戦闘の反応が必要。BASE-017とBASE-023はともに時間追加なので、時計という同族の物体であることを意図的に残したが、通常の報酬選択で差が誤読されないかは未検証。`KEN-011 v3` は手札の主題が小さく、v4へ差し替え候補とした。
