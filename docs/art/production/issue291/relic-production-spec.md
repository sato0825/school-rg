# レリック原画制作仕様 — Issue #291

対象は現行11 ID。レリックは「持ち運べる学校の物体」として、戦闘HUDの小さな所持品欄、報酬・ショップの選択、詳細表示を同じ原画から作る。画風は中学生向けの紙地ガッシュ。濃紺の明瞭な輪郭、青緑・藤色の控えめな面、珊瑚色は一点だけ。絵の中心70%に主題を収め、透明余白を残す。文字、レアリティ、効果数値、枠は原画に入れずUI側で表示する。

## 制作・採用ゲート

1. IDと効果から主物体を一つ決め、同名や近似効果の既存候補と外形を照合する。
2. 元プロンプトと生成原本を版付きで保全し、SHA-256・寸法・透過有無・元パスを記録する。生成seedと編集可能ソースは提供されていないためnull。
3. 48px所持品欄、64px選択、128px詳細、グレースケールで主物体を判別できるか目視する。色のみで効果を区別しない。低刺激状態では輝き・点滅を増やさない。
4. 効果は名前と短い説明を隣接表示し、絵だけに数値や発動条件を背負わせない。正式採用は実ゲームの背景・隣接物体・フォーカス/読み上げ・権利審査後とする。

## 第1群の検証

`prompts.json` が4点の生成原文、`assets-v1.json` が原本・SHA・候補状態。`qa-board.html`/`qa-board.mjs` により48px、64px、128px、48pxグレースケールを同一画面で確認した。`qa-board-1024-v1.png` は目視証拠。全16表示画像がロード、横スクロールなし。4点は縮小時に柄・帳面・靴・スタンプを区別でき、グレースケールでも外形が残った。候補を `preferred-draft` としたが、`acceptedVersion` は全件null。

既存のしおりプレビューは布や金属の写実的な陰影が強く、#246の透明切抜き2点と画風が揃っていない。#242/#246のファイルは各PRブランチにあり、この枝には未統合。既存3件を単に「候補あり」と数えて採用可能とみなさない。残る4件は未制作。第1群後の台帳は101素材中候補54・未制作47、レリック単独では候補7・未制作4・正式採用0。

現行#261本編の所持レリックHUDは文字チップなので、このボードは**導入前の寸法検証**である。本編に画像を接続して隣接・背景・ツールチップを確認する工程が残る。`#247` のレアリティは未決定であり、ここでは推定しない。
