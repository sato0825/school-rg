# LIT-004 `outline` 質感改稿 — Issue #296

独立監査で、旧候補は窓際の木目・紙への写真寄りの光と3D陰影が強く、同じ文芸部手札の物体中心の原画と並ぶと質感がずれると指摘された。#242の旧候補とverse/drawをSHA付きで比較用に複写した。原本は#242ブランチに保全されている。

`outline` は2枚ドローと時間+1秒。新候補では開いたノートに2枚の白紙片、時間を示す藤色の弧を置く。色・枠・レアリティ・英字名は絵に含めない。v2は窓際机を排除できたが平板なフォーム状で、既存の筆触と合わないため候補から外した。v3はノートの紙厚と水彩影を加えた。

`provenance.json` に旧候補と比較用絵、v2/v3のID・版・元パス・SHA・寸法・状態を記録する。旧候補は `comparison-only`、v2は `superseded-candidate`、v3は `preferred-draft`。正式採用は全件未実施。

## 実寸確認

`node docs/art/production/issue296/qa-board.mjs` で1024/1440pxの手札・報酬・48px中央クロップを出力。`qa-board-1024-v1.png`/`qa-board-1440-v1.png` はv2、`qa-board-1024-v2.png`/`qa-board-1440-v2.png` はv3との比較。画像全件ロード、横はみ出し0、効果文のカード外はみ出し0。目視ではv3の主題が手札と48pxでも判別でき、旧候補の強い木目・写実陰影を解消した。

隣のverse/drawも場面描写と陰影が強いため、文芸部全カードの質感統一が完了したとは言えない。報酬での並びと実ゲームの背景・動き・効果文字、#242/#261の原画枝との統合、権利審査、正式採用判断が残る。#247のレアリティは未決定のまま。
