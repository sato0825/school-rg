## 制作テンプレート

1. **情報**：カード ID、クラブ、入力語、種類、対象、効果 kind と具体値から、主題を1つ、補助動作を1つ選ぶ。画面の文字に頼らず、同じデッキ内で似た輪郭のカードを区別する。レアリティは絵に描き込まない。
2. **絵柄**：中学生の部活道具が主役。落ち着いた涼色の薄いガッシュ面と細い濃紺輪郭。人物、背景、敵の既存候補と照合する。写真的・劇画的な材質、過密な小物、擬似文字、常時発光を避ける。演出時の光は UI 側に分ける。
3. **構図**：元絵は 3:2 横長。戦闘手札の約 2:1 絵窓と、48×48 の縮小見本で両方重要部位が残ることを目標にする。主題は中央 60% 幅・60% 高さから始め、実表示で検査する。白紙の余白も小サイズで判別できる程度に抑える。
4. **保存**：1 ID/版ごとに別ファイル。`card-<club>-<input>-vN.png` とし、上書きしない。原指示、生成ツール、原本パス、SHA-256、寸法、透過、seed の有無、編集可能元データ、権利、採否と QA を台帳に書く。PNG のままでは編集可能元データを満たさない。
5. **検査と採用**：48px、118×113 手札、190×228 報酬、1024×768、1440×900、グレースケール、低刺激で比較する。初見プレイヤーが名前を隠して区別できるか、絵と効果が食い違わないか、人手で判定する。実 UI 統合と実機 iPad/PC はその後。採用は #29/#248 の人手ゲートを通した時だけ更新する。

## 実表示の検証と限界

- `qa-48.png`: 48×48 のスクエア窓で5主題は輪郭で区別できる。ただし Jot/Leaf など同一部活全デッキを同時に並べた判定ではない。
- `qa-1024.png`, `qa-1440.png`: 190×228 の報酬3枚と、現行相当 118×113 の手札5枚を静的に並べ、全画像を読込。横はみ出しなし。5枚の主題と入力語は目視で違いが分かる。`qa-1024-grayscale.png` でも輪郭は残る。
- **未合格**：現行相当の手札 118×113 では効果文字が 8px で小さく、実戦闘での判読を合格にできない。これはアートだけでは直せず、#242/#243 のカード面積・情報配置設計へ返す。報酬の効果文字も 11px で人手評価が必要。
- KEN-001 v1 の絵窓裁ち落としが大きかったため v2 に差し替えた。v1 も版履歴として保存し、`superseded-candidate` とした。v2 の紙帯端はまだ余白境界に近く、採用前に正規 art window で再確認する。
- この静的見本にゲームの手札選択・タイピング・敵・発動・報酬遷移はない。#242 担当へ画像を共有済み。PC/iPad のブラウザー実表示、物理 iPad、初見プレイヤー評価、ゲーム UI への統合は未確認。
