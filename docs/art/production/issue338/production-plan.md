# #338 第7波の制作判断

未制作18カードのうち、共通の持続/代償/条件行為5件と5部活の固有行為を1件ずつ選ぶ。優先理由は、報酬で動作が似るカードの区別と、持続効果を一回の攻撃絵で誤読させないため。
