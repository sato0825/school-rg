# ポーション6種の原画体系 — Issue #309

現行6 IDのうち `potion-ink` は#246に原画候補がある。残る5 IDをそれぞれ固有の容器・物体で制作した。既存インク候補は比較用にSHA付きで複写した。画像は全て候補で、正式採用、#261本編接続、権利審査は未実施。`#247` のレアリティを絵に焼き込んでいない。

| ID / 入力語 | 物体と外形 | 効果 | 絵だけで推定できること | 絵だけでは確定できないこと |
|---|---|---|---|---|
| potion-time / clock | くびれた砂時計瓶＋弧 | 時間追加 | 時間に関わる瓶 | 追加秒数・使用条件 |
| potion-heal / bandage | 巻いた包帯＋紙包み | HP回復 | 手当て・治療 | 回復量・対象 |
| potion-ink / ink | 角瓶＋濃いインク | 単体攻撃 | インクを使う道具 | 攻撃かどうか・敵1体・ダメージ量 |
| potion-guard / shield | 段ボールの五角盾 | 防御 | 守りの道具 | 防御量・持続 |
| potion-splash / splash | 丸底フラスコ＋3方向の滴 | 全体攻撃 | 広い範囲への色水 | 敵全体へのダメージ量 |
| potion-tea / tea | 蓋付き茶杯＋湯気 | 回復と時間追加 | 温かい飲み物 | 複合効果と数値 |

これらは制作担当の目視推定であり、対象ユーザーの意味理解を測定した結果ではない。絵は「何の道具を使うか」「大まかな作用」を示し、対象・発動条件・数値は隣接する名前と効果文で確定する。使用時は道具から対象へ結果をつなぐアニメーションが必要。例えば色水なら3方向の着弾、包帯ならHPバーの増分、砂時計瓶なら時間ゲージの延長を同じ瞬間に示す。汎用記号や説明チップだけで代用して合格とはしない。

## 原本と検査

`prompts.json` に5原画の生成指示、`assets-v1.json` に版・元パス・SHA-256・透過・候補状態を記録。`reference-ink.json` は#246原画の比較用コピーを照合する。`qa-board.html` と `qa-board.mjs` は48px所持品欄、64px選択、128px詳細、48pxグレースケールに加え、絵のみ・文字のみを切り替えて撮影した。24/24画像ロード、横はみ出し0。48pxでも、砂時計瓶・角瓶・丸底フラスコの形は別々に見える。段ボール盾の端、包帯の巻き、茶杯の取っ手も残る。

制作台帳は101スロット中候補63、未制作38、正式採用0。カード46/84、レリック11/11、ポーション6/6に候補があるが、本編での表示数と採用数は別指標。#261実ゲームのポーション欄・取得画面・入力発動・複数対象・低刺激設定での表示、色覚/読み上げ/実機iPadの確認が残る。
