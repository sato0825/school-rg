# Issue #142 カード枠の視覚規則と実画面確認

戦闘・報酬・ショップのカード表示に、学校の紙札と印章を共通の視覚規則として使う。通常時の背景は落ち着かせ、カード選択や発動時の短い演出と競合させない。

| 種別 | 線と印章 | 基調 |
| --- | --- | --- |
| ATTACK | 角を持つ赤い印章 | 赤系の淡い紙面 |
| SKILL | 丸い青緑の印章 | 青緑系の淡い紙面 |
| POWER | 四角を回した印章 | 紫系の淡い紙面 |
| STATUS | 破線の印章 | 青灰系の淡い紙面 |
| CURSE | 破線の暗い印章 | 暗い青灰の淡い紙面 |

色に加え、印章の形、上辺、種別ラベルで判別する。文字と効果は紙面の上に残し、入力候補は輪郭、非候補は減光、選択は縁、キーボードフォーカスは黄色の輪郭で示す。カード名の長い語も改行できる。描画は `data-card-kind` による表示のみで、カード効果・入力判定・時間は変更しない。
