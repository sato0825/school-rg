# 科学部・同一人物3ポーズ制作パイロット

親: [#29](https://github.com/sato0825/school-rg/issues/29)、作業: [#233](https://github.com/sato0825/school-rg/issues/233)。基準画でユーザーが受け入れたのは中学生らしい年齢感と柔らかい作画方向のみ。これらの個別ポーズと最終アートは未承認。

## 同じ人物として固定したもの

待機v2を編集対象にして発動・被弾v3を別々に制作した。画面左の髪留め2本、顔・瞳の形、制服の金ボタンと青緑のリボン、ノートの3色タブ、鞄のタグ、靴と靴下は3枚で確認できる。青系の線と影も近い。背景・エフェクトは画像へ描き込まず、戦闘画面で別レイヤーに置く。

| 状態 | 素材 | 判断 |
| --- | --- | --- |
| 待機 | `serious-student-idle-candidate-v2.png` | #178からの人物マスター候補。方向性のみ採用で、原本なし。 |
| 発動 | `serious-student-activate-candidate-v3.png` | 鉛筆を右へ向ける動作は明瞭。腕が大きく横へ伸び、旧v2より人物の幅が広いのでステージ上で干渉を確認する。 |
| 被弾 | `serious-student-hit-candidate-v3.png` | 顔・髪・小物は維持し、短い驚きとして読める。足元が待機より約30px高く、切替時の浮きがないか戦闘画面で確認する。 |

新しい2枚は1024×1536 RGBA、透明画素と描画画素を持つ。足元の透過外接矩形は待機v2がy=1501、発動v3が1502、被弾v3が1471。これらの数値はスケールと接地の目安であり、顔や服の同一性は自動的には証明しない。制作指示とSHAは[制作記録](prompts/serious-student-pose-pilot-v3.md)・[素材台帳](asset-register.json)に残す。

開発用 `?artPreview=sciencePilot` のみで待機v2→発動v3→被弾v3の切替を確認できる。通常ゲームの科学部素材はv2のまま維持する。PC戦闘画面で入力完了・敵攻撃と時計/Intentの同期、1440px・1024px・390pxでの配置を検査する。実機iPadでの確認結果は別途記録する。

**保留理由:** 画像は生成PNGであり、髪・顔・手・服などを共有する編集可能な部位別原本と中間フレームがない。同じ入力を繰り返して一定品質を量産できる証拠、5人と敵・背景の統一画風、人による採否も未完。候補を正式採用せず、#29を開いたままにする。
