# Issue #179 Act内ステージ候補レビュー

## 現状と変更範囲

- 通常ランの階層数は暫定12階層/Act、3 Act。短縮E2Eは2階層/Act。階層数は約60分の実プレイで最終調整する仕様であり、背景数とは別。
- 変更前はActごと1環境プレート、全3枚。変更後は各Actの前半と後半で異なる学校内の場所を表示し、全6枚。3枚の新規画像は候補であり、最終アート採用ではない。
- 背景選択は保存済みマップノードのActと階層から導く。通常ランは1〜6Fが前半、7F以降とボスが後半。短縮ランも総階層を使って前半/後半を分ける。乱数、戦闘処理、セーブ形式を変更しない。
- マップの現在地と戦闘は同じ `stageUrlForRun` を使用する。人物、敵、エフェクト、HUDは背景と独立した層のまま。
