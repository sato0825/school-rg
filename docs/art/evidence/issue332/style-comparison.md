# 3人の戦闘リグの比較（候補レビュー、2026-10-31）

基準は `docs/art/reference/five-students-lineup-draft.png` と #29 の「同じ品質で反復制作し、別レイヤーで動かす」方向です。横並び画像自体も最終承認素材ではありません。美術部 v2 を、文芸部 v3・軽音部 v2 の原本と同じ 1024×1536 キャンバスで比較しました。

| 指標 | 美術 v2 | 軽音 v2 | 文芸 v3 |
| --- | ---: | ---: | ---: |
| 頭部レイヤー高 / 可視全身高 | 325 / 約1425 = 22.8% | 348 / 約1469 = 23.7% | 470 / 約1369 = 34.3% |
| 顔輪郭の幅（髪を除くラフ目視） | 約202 px | 約186 px | 約202 px |
| 顔輪郭の幅 × runtimeScale | 約202 px | 約203 px | 約220 px |
| 頭部の可視画素平均彩度 | 0.258 | 0.322 | 0.476 |
| 胴部の可視画素平均彩度 | 0.309 | 0.361 | 0.422 |
| 頭部の高コントラスト隣接辺率 | 0.0705 | 0.0645 | 0.0732 |
| 胴部の高コントラスト隣接辺率 | 0.0553 | 0.0606 | 0.0585 |
| `groundY` | 1534 | 1514 | 1509 |

彩度は alpha≥128 の画素について `(max(R,G,B)-min(R,G,B))/max(R,G,B)` の平均です。高コントラスト隣接辺率は alpha≥128 の上下左右隣接ペアについて輝度差≥30/255 の割合です。原本 `head.png` と `torso.png` を同じ ImageMagick RGBA8 の条件で計測しました。衣装と髪の色面、明暗、素材内の細線の分布が混ざるため、辺率は線の**太さそのもの**ではありません。顔輪郭寸法もセグメント境界を厳密にトレースしていない概算です。

## 判断

美術の頭部レイヤーは文芸の大きな髪より小さい一方、髪を除いた顔幅は軽音の runtime 表示とほぼ同じです。#29 の横並びでも、美術の灰褐色ボブ、落ち着いた表情、淡い絵の具付き羽織と画板は固有の人物像です。彩度を一律に上げるとこの違いを失います。袖・画材の細線は 1024 と 1440 の戦闘スクリーンショットで崩れず、首/肩と足底/影に明白な離れは見つかりませんでしたが、接合の最終判断は人が行います。

`art-rig-candidate-v3.json` は原本 PNG を保ったまま、全身1.09倍・頭部1.10倍を試した**未選択の比較候補**です。1024/1440 実画面で表示を確認後、顔の実寸を揃える根拠が不足すると判断し、稼働リグは v2 に戻しました。v3 を最終採用・品質改善と扱いません。v2 の動画と画面はこのディレクトリに保持しています。
