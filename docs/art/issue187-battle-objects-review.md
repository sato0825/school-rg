# Issue #187 戦闘のカード束と状態表示

## 役割

- 山札・捨て札・除外は異なる束の形と枚数で区別する。現在の枚数はそれぞれ `aria-label` でも伝える。束の中身の閲覧は本変更に含めない。
- プレイヤーと敵の状態は、種類ごとの記号・輪郭・色・短い名称と数値を併用する。色だけで意味を伝えない。未知の状態IDは汎用記号とIDで表示する。
- カードは既存の種別印章と文具モチーフを保ち、束ねた紙札の厚みと手札のわずかな角度を加える。低刺激表示と動きを減らすOS設定では角度をなくす。
- キャラクターの近くに現在確定している部活名を示す。個人名は未決定のため Issue #188 で設計判断を追跡する。背景・人物・敵の画像は現行の制作候補を使い、正式採用は Issue #29 に残す。
