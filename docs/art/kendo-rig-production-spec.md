# 剣道部リグの作画仕様・再制作条件（Issue #330）

この文書は候補原画から抽出した**再制作用の制約**です。画像生成時の完全な入力文の記録ではありません。候補の出自と未承認点は `issue330-kendo-rig-review.md` を参照してください。

## 人物固定

- 佐伯りつ。中学生の女子。背を大人びて長く見せない。青黒い髪を片側で結び、細い青いヘアバンド。落ち着いたが活動的な表情。
- 紺の運動部ジャケットに白いライン、白いタオル、青系チェックの制服スカート、紺ソックス、白と紺の運動靴。
- 竹刀は一本で、手にした竹刀と背中の紺色筒形ケースを区別する。どのポーズでも手首・柄・剣先の接続が読める。
- 観客の方へ体を3/4向きにし、敵は画面右。戦闘舞台の床と両足を接地させる。背景の光や陰影に人物を溶け込ませない。

## レイヤーと動き

- 1024×1536透過キャンバス。背面の竹刀袋、左右の脚、胴体、左右の腕（利き腕に竹刀）、頭、差分表情を独立レイヤーにする。位置・SHA・関節は manifest に定義。
- 待機: 両足の接地を固定し、呼吸と竹刀先端のみ小さく動かす。全体を揺らさない。
- 防御/反撃: 肩を閉じて竹刀を体の前へ戻す。カードの解決と同時に反応する。
- 攻撃: 踏み込みと竹刀の振りを一つの短い動作として同期する。敵のHP変化より前に命中を先取りしない。
- 被弾: 顔の差分、体幹と竹刀の受けで伝える。舞台やHUDを移動しない。
- 勝敗: この候補には固有絵が未制作。結果画面との接続を含め別途制作し、現候補を完成扱いにしない。

## 次の作画受入条件

1. 襟と首、袖と肩、利き手と竹刀柄、膝と靴の接合を原画レイヤーで修正し、拡大表示でも透過の穴や継ぎ目がないこと。
2. 待機・防御・攻撃・被弾・勝敗を並べ、同一人物、同じ身長と制服、竹刀一本を確認すること。
3. 1024×768と1440×900の実戦映像で、剣先、足元、敵とHUDの重なり、複数敵、低刺激静止を確認すること。
4. キャラ名と数値を隠して、守り・攻撃・被弾が初見で区別できるか人が評価すること。物理iPadの表示と入力を別に確認すること。

採用判断前に原画と候補履歴を上書きしない。変更時は新しい版を作り、SHAとレビュー結果を併記する。
