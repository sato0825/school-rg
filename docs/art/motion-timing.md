# 戦闘アニメーションの時間軸（#90）

戦闘画面はカード名のキー入力でも再描画されます。待機ループは単調時計の位相から負のCSS `animation-delay` を計算し、再描画後も同じ動きの位置から表示します。発動・敵行動・被弾は各イベントの開始時刻を使い、再描画で動きを巻き戻しません。連続してカードを使った場合は新しい発動を開始し、前の終了タイマーで消さないようにします。

時間の長さは `src/ui/motion-timing.ts` に集約します。これは表示専用です。入力制限時間、ターン遷移、敵Intentに独立したリアルタイム時計を追加しません。低減モーションの設定では既存のCSS規則がアニメーションを短縮します。画像は独立した差し替え対象で、候補ポーズや3枠仮配置を完成アートとは扱いません。
