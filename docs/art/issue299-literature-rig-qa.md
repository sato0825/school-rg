# #299 文芸部 部位別モーション候補 QA（2026-10-31）

## 対象と受入境界

#29/#31 に向けた**文芸部1人の候補**。GameShell の1戦において、待機では呼吸・重心、カード使用ではノートを掲げる腕と上体、被弾では顔・頭・上体・腕・脚を動かす。被弾時は驚いた顔レイヤーへ切り替え、文字を読まなくても攻撃を受けたことを示す。HP減少・カード効果のゲーム状態は既存イベント時計が確定させ、このリグはその確定状態を表示する。敵の行動やゲームロジックを CSS 時間で進めない。

部位画像と 7 層の OpenRaster 原本はそれぞれ保存。`literature-rig-candidate-v2.json` に頭・胴・両腕・両脚・被弾表情の位置、関節、接地、SHAを記録。新しい絵が必要な際は画像の差し替えとマニフェスト更新で既存戦闘ロジックに触れずに交換可能。顔差分のみ画像生成原出力から共通ヘッドキャンバスへ正規化しており、手描きの修正がまだ必要。
