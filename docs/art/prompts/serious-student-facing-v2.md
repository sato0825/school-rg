# 科学部の右向き3ポーズ候補 v2

Issue: #178。制作方法: 組み込み imagegen の透過画像編集。モデルの内部版・乱数・編集可能な部位別原本は公開されていない。出力PNGは候補であり、#29 の最終アート採用を意味しない。旧 v1 は変更せず保存した。

## 入力と固定条件

- 待機: `serious-student-idle-candidate-v1.png` を編集対象とした。
- 発動: 上記から作った `serious-student-idle-candidate-v2.png` を編集対象とし、旧発動 v1 を動きの参考にした。
- 被弾: 待機 v2 を編集対象とし、旧被弾 v1 を反応の参考にした。
- 全状態で中学生に見える体格、柔らかい線と陰影、顔・髪型・制服・青緑の髪留めとリボン、鞄・ノート・鉛筆を固定。画面左の鞄、画面右のノートを保つ。背景・UI・エフェクトを含めず、本物の透過背景とする。

## 実際に与えた編集指示の要点

1. 待機: 同じ人物と全身比率を保ち、頭・目と上体を右側の敵へ向ける。背面を見せず、顔を読める斜め向きにする。画像全体の左右反転は使わない。
2. 発動: 待機 v2 を基準に、鉛筆を持つ手だけを上げ、ペン先を画面右へ向ける。顔・目も右向きのまま。鞄とノートの画面上の位置を入れ替えない。
3. 被弾: 待機 v2 を基準に、肩を少しすくめ、膝を軽く曲げ、ノートを引き寄せる。驚いた表情にしつつ右側を向く。浮いた記号を除き、エフェクトは別レイヤーに置く。

発動の初回出力は鞄とノートが逆転したため不採用。被弾の初回出力は頭の横に独立した青い驚き記号が混入したため不採用し、記号を除いた修正版を v2 とした。棄却出力は実行記録上の生成物で、ゲーム参照と台帳には含めない。

## 現状の制約

3枚は同一人物に見える候補だが、部位別原本と中間フレームがない。別制作回での再現性、動きの補間、全5部活の最終的な統一品質は未検証。採用判定は #29 の基準画・3ポーズ比較とレビューを通す。
