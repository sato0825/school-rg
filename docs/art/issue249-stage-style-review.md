# Issue #249 紙・ガッシュ調の校内舞台比較

## 比較条件

同一seed 42、文芸部、Act 1の戦闘開始後に時計を一時停止し、背景画像だけを差し替えた。人物・敵・Intent・カード・HUD、キャラクター位置、ゲーム状態、画面幅は共通。新候補は開発用PlaywrightでDOMの背景だけを差し替えたため、ランタイムの採用済み素材には変更していない。

## 実画面で確認したこと

- 新候補は現行廊下の鏡面床と強い窓反射を弱め、紙・ガッシュ調の面、濃紺の細線、涼色低彩度を導入できている。人物と敵を背景から独立したレイヤーとして置く広さは保たれた。
- 1440pxと1024pxで人物、敵、Intent、HP、タイピング行、手札の位置は保たれ、画像は元解像度でデコードできた。背景は同じ戦闘UIに差し替え、リロードで元の廊下に戻ることを確認した。
- 既存の人物の肌・髪・制服や敵の輪郭は新背景より濃く、視覚的な主役として前に出る。一方、アトリウムの白い床面はまだ明るく、#243の新しいカード/情報配置と組み合わせたときの視線誘導は未評価。
- 人物、敵、カードのイラストを含む最終的な画風統一や読みやすさは人間の視覚判断が必要。現行UIは#243で全面再設計されるため、この比較を最終採用の根拠にはしない。
