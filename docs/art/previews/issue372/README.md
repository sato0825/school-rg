## 絵のみ／文字のみの判定

| 組 | 旧候補の衝突 | 改稿候補の実寸判定 | 文字で確定する情報 |
|---|---|---|---|
| reread / edit | 青い閉じた本と開いた本が同じ机の視点 | edit v2 は紙を通す編集機構の輪郭となり、閉じた本と区別しやすい | 捨て札回収・防御と、手札除外・2枚ドローの違い |
| observe / buffer | 丸いレンズと丸い薄い防護輪が隣接 | buffer v4 は長方形の防護面に変更され、レンズと形が分かれる | 弱体・ドローと、防御・弱体解除の違い |
| stance / breath | 防具の正面展示と防具の正面配置 | breath v2 は横に寝た防具と気流になり、立った防具との差が分かる | 防御8・ドローと、防御4・反撃3・ドローの違い |
