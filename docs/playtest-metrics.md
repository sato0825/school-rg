# 実プレイ計測 v0.1

子Issue [#88](https://github.com/sato0825/school-rg/issues/88)、親 [#68](https://github.com/sato0825/school-rg/issues/68)。約60分という目標の実測に使うための記録形式です。この実装だけで所要時間や離脱率を測定したことにはなりません。

`?playtest=1` を付けて起動すると、端末内の `school-rg-playtest-v1` に計測を保存します。通常起動では計測しません。ランの開始地点、訪問地点、戦闘ノード、結果、可視状態で操作できる間の経過時間を記録します。戦闘を一時停止した時間とタブが非表示の時間は加算しません。敵フェーズ、マップ選択、購買などの操作時間は含めます。

再読込ではランと計測の部活・シード・難度を照合し、保存済み時間から再開します。途中から計測を有効にした場合は `partial: true` と表示します。読めない計測データは上書きせず、画面にその状態を表示します。新しいランを明示的に開始すると新しい計測へ切り替わります。

終了画面の「計測JSONを保存」だけがファイルを出力します。外部送信はありません。JSONは `formatVersion: 1`、ランID、部活、シード、難度、`activeMs`、訪問履歴、戦闘ノードID、勝敗を含みます。プレイテストではこれに加えて主観的な難度、不具合、離脱理由を別途収集し、5部活とAscension段階ごとに約60分目標との差を評価します。
