# レリック・ポーション追加候補（Issue #118）

`src/content/extra-consumables.ts` に効果量と追加データを分けた。名称と数値は3 Actの実プレイによる調整前の仮案であり、管理シートに確定値がある項目はそちらを優先する。

| 種類 | 名称 | タイミング・入力 | 仮の効果 |
| --- | --- | --- | --- |
| レリック | 出席のスタンプ | 取得、戦闘終了 | 6G、以後の戦闘終了ごとに3G |
| レリック | 学食の引換券 | 戦闘終了 | 生存時にHP2回復 |
| レリック | 予備の絆創膏 | 被弾 | 生存しHP損失があればHP1回復 |
| レリック | 練習用タイマー | カード使用 | 入力時間400ms加算、上限は共通設定に従う |
| ポーション | 厚紙の盾 | `shield` | ブロック8 |
| ポーション | 色水の小瓶 | `splash` | 生存中の敵全員に4ダメージ |
| ポーション | 温かいお茶 | `tea` | HP3回復後、入力時間1秒加算 |

ショップと宝箱はコンテンツ一覧から候補を生成するため、新規品も既存の決定的な抽選経路に入る。ポーションは戦闘中にF2で切り替え、名前を直接入力して使用する。所持枠は共通設定に従い、既存品と同様に保存・復元できる。

## 実画面確認

[390×844の戦闘画面](content/previews/issue118-potions-narrow-v2-20261031.png)で3種類を所持した状態を表示し、`splash` → `shield` → `tea` の入力を確認する。所持品は3列に並び、切替ボタンと各アイテムが画面内に見える。画面のリスト表示は共通UIで、固有アイコンやアートは未制作。取得頻度、スタック時の強さ、約60分のランでの価値は #68 で調整する。

最初の[表示候補](content/previews/issue118-potions-narrow-20261031.png)では、3本所持時に切替ボタンが細くなり縦書き状になったため不採用とした。v2では切替と所持品を別行にし、3本を横並びにした。
